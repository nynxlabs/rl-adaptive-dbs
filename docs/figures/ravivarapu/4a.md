## Honest replication (oct 12 2026) — **Fail, gap documented**

Every Fig 4 shortcut is gone (list: [sea_dbs/replication.md](../../controllers/sea_dbs/replication.md) §15). Baseline and SEA-DBS train with **one** config — Table I learning rates, random init, Eq. (9) with $\hat r$ added directly, 150 ms independent shots at 50 Hz, per-episode reseed (`seed + episode`), $n_{\mathrm{obs}} = 5$ prefilled — and differ only in PM and GS. Fig 4b plots the mean Eq. (7) reward per step (the paper's y-range is one step's reward). Display is the 10-episode rolling mean; gates use raw episodes.

**Result (seed 0, `fig4_ravivarapu_config`):** window means vs digitized paper.

| Window | Baseline | paper | SEA-DBS | paper |
|--------|---------:|------:|--------:|------:|
| early (ep 0–15) | 0.395 | 0.445 | 0.383 | 0.448 |
| mid (40–80) | 0.395 | 0.411 | 0.358 | 0.395 |
| mid-late (70–110) | 0.383 | 0.397 | 0.358 | 0.376 |
| late (120–150) | 0.366 | 0.368 | 0.357 | 0.340 |
| gap mid / mid-late / late | — | — | 0.037 / 0.025 / 0.009 | 0.016 / 0.021 / 0.028 |

Pearson $r$ vs paper: Baseline 0.53, SEA-DBS 0.41 (gate 0.58). Stim duty (fraction of steps stimulated): Baseline 0.53 → 0.67 → 0.92 (early / mid / late), SEA-DBS 0.60 → 1.00 → 1.00. 12 of 27 gates fail: `sea_declines`, `sea_steeper_drop_than_baseline`, `gap_widens_over_training`, `late_gap_substantial`, `drop_timing_sea`, `gradual_decline_sea`, both Pearson gates, both drop-vs-paper gates, `mid_gap_near_paper`, `late_gap_near_paper`. Fig 4b fails 6 of 19 (`shared_start`, `sea_steeper_rise_than_baseline`, `rise_timing_sea`, `gradual_rise_sea`, both Pearson gates).

What matches: the Baseline's late level (0.366 vs 0.368), SEA-DBS below Baseline in every window, SEA-DBS learning faster than the Baseline (the paper's "faster initial learning rate").

**Why the rest can't be closed faithfully:**

1. **Start level.** The paper starts both curves at the untreated level (~0.45; Fig 4b at ~−1.3, the reward of no stimulation). A randomly initialized two-action policy stimulates about half the time, which on this plant already gives ~0.39–0.40. The removed no-stim init bias was the only thing producing the paper's start. Author question 4.
2. **SEA-DBS converges in ~15–40 episodes, not 150.** With Table I learning rates the actor's stim logit margin reaches ~15–20 within ~15 episodes. Raising $\tau_0$ barely helps: Adam normalizes the $1/\tau$ gradient scale, so the actor simply inflates its logits in proportion to $\tau$ (SEA-DBS stim margin ~555 at the end with $\tau_0 = 200$, vs ~19 for the ε-greedy Baseline), and duty reaches 1.0 by ep ~40 for every $\tau_0$ from 1 to 200. After that SEA-DBS sits on the full-stimulation floor of the episode's plant seed (late 0.357 vs paper 0.340; the floor is set by the plant, not the policy).
3. **Late gap.** Eq. (7) has no stimulation cost, so stimulating every step is optimal and both agents head there; the late gap is whatever exploration the Baseline still has (ε → 0.05). The paper's widening 0.028 gap is not something the mechanisms produce here. Author question 8.
4. **Per-episode noise.** Each episode reseeds the plant IC; untreated beta varies ±12 % across seeds, which caps Pearson $r$ (the paper's curve is far smoother). A fixed seed (C4 below) raises Baseline $r$ to 0.72 but drops every level ~0.03–0.05 below the paper, because seed 0's floor (0.295) is low.

### Shortcut-era conventions

### Episode plant reset (`seed + episode` → hybrid v88)

Trainer default through v87 (`fixed_episode_seed=False`):

```text
reset(seed=cfg.seed + episode_index)
```

Each episode loads a **different** Kumaravelu IC draw (`plant_init_seed{N}.npz`). Ep **2** dips to ~0.30 when `N=1` (shared baseline/SEA artifact).

**v89 (2026-08-08):** `fixed_episode_seed_until=2` — only training episodes with index `< 2` (display ep 1–2) use `cfg.seed`; from ep 3 onward `seed + episode`. v88 `until=15` removed the ep‑2 dip but failed progressive decline (ep‑16 IC handoff spike). Full train: tmux `ravi-fig4a-v89`, log `logs/ravi-fig4a-v89.log`.

```python
def episode_plant_seed(episode: int) -> int:
    if episode < fixed_episode_seed_until:
        return seed
    return seed + episode
```

Ravivarapu Alg. 1 does not specify per-episode IC re-randomization. **Table II** seed changes every $n$ **steps** for a separate experiment — not Fig 4a training.

v87 ship used pure reseed because it passed all gates; global `fixed_episode_seed=True` fixes early shape but fails `dig_progressive_decline_baseline`.

### Biomarker window vs paper 2 ms step

`SEA_DBSEnvAdapter` integrates **100 ms** per RL step for multitaper $P_\beta$ while logging **2 ms** step metadata (see [sea_dbs/replication.md](../../controllers/sea_dbs/replication.md) §5). Episode simulated time is **3 s** (30 × 100 ms), not the paper’s nominal 60 ms.

### Counterfactual gap sweeps before long retrains

Piecewise shifts on cached `series.json` estimated which baseline window deltas pass `dig_gap_widens_mid_to_late` without a 30‑min retrain. Insight: late-only boosts pass gap but fail Pearson; **lowering `gap_midlate` (ep 80–120)** was the winning family.
