**Entry point:** `scripts/figures/papers/mehregan/4a/plot.py`

## Paper target

Per-step GPi beta-band power during DDPG training on the **45 Hz** fixed-mean pattern alphabet: **300** environment steps (10 episodes × 30 steps). Y-axis **PSD(x10³)** = raw $P_\beta / 1000$. Digitized paper: early (steps ≤130) mean ~0.49, late (≥150) ~0.38, drop ~0.11; mid [120,150] ~0.445 vs early [0,100] ~0.49 (modest mid fade over ~30 steps, not a vertical cliff).

## Digitization revisit (2026-08-13)

Fig 4b episode-mean PSD is the same training run averaged per episode. **Phase 1:** match **episode 0** to digitized paper (~0.50, near untreated Fig 2a) before chasing the late floor. τ **3→1.4** (v30) did not prevent late pattern-0 collapse and left ep0 at ~0.44 (already suppressing).

| Diagnosis | Evidence |
|-----------|----------|
| Late cliff = pattern-0 collapse | v4/v18/v30: episodes 0–4 mixed (~18–24 unique actions, β≈0.40–0.44); later episodes ≥90% action 0, β≈0.30 |
| Paper ep0 is untreated-like | Digitized 4a steps 0–29 ~0.507; 4b ep0 ~0.498. Fig 2a untreated late ~0.471 on this scale |
| Pattern 0 cannot raise ep0 | Regular 45 Hz mean β ≈ 0.29 on this plant. v30 ep0 never selected pattern 0 |
| Reward goes positive because late β < $β_t$ | Eq. (8) linear branch when $s < 0.35$; paper late ~0.37 stays quadratic-small / near 0 from below |

**Phase-1 knobs** (paper-silent; Fig 4a `plot.py` defaults): `--init-bias-scale 0` (do not bias toward the suppressor) and `--jitter-fraction 0.5` (library alphabet is $1/3$). Fresh train — do not `--resume` v30 (jitter / init are material). New gates: `ep0_near_paper` (4a, 10% rel) and `ep0_beta_near_paper` (4b). Late-floor gates stay required for full exit but are not the iteration target until ep0 passes.

**Phase 1 result (v31 series / 4b v33):** ep0 PSD 0.499 vs digitized 0.498 (`ep0_near_paper` / `ep0_beta_near_paper` true); ep0 reward −76 vs paper ~−80. Collapse still starts at episode 5 (70% pattern 0) and is 100% pattern 0 for episodes 6–9 (late PSD ~0.29, late reward +16).

**Phase 2 result (v33 series / 4b v34):** `--temperature-end 1.6` only delayed the cliff (ep5 53% pattern 0 vs 70% at τ 1.4). Episodes 6–9 were still 100% pattern 0; late PSD ~0.29 / late reward +16. Ep0 stayed in the 10% band (0.527 vs digitized 0.507). Same suppressor floor as τ 1.4 — temperature alone does not keep late β above $β_t$.

**Phase 3 result (v34 series / 4b v35):** `--entropy-coeff 0.05` kept ep0 in band (0.513 vs digitized 0.507; `ep0_near_paper` true) but late still collapsed: episodes 8–9 were 100% pattern 0, late PSD ~0.310 / late reward +14.8 (`late_beta_above_threshold`, `late_beta_near_paper`, `late_reward_near_zero` false). 4a `mid_fade_vs_paper` also false.

**Phase 4 result (v35 series / 4b v36):** `--entropy-coeff 0.15` (Fig 6a) kept ep0 in band (0.490 vs digitized 0.507; `ep0_near_paper` / `ep0_beta_near_paper` true) and softened the cliff slightly (late step-mean 0.328 vs 0.310 at 0.05; 4b `late_beta_near_paper` true at 0.319) but **still failed** `late_beta_above_threshold` (β_t=0.35) and `late_reward_near_zero` (+6.2 vs paper ~−2). Episodes 8–9 were 93%/100% pattern 0 (same suppressor floor). 4a `mid_fade_vs_paper` still false.

**Structural blocker (2026-08-14):** entropy probe budget exhausted (0.05 → 0.15; ep0 held). Late PSD cannot reach digitized ~0.37 without leaving the pattern-0 attractor on this 45 Hz plant — pattern 0 mean β ≈ 0.29 is below $β_t$ and drives positive reward via Eq. (8) linear branch. Do not invent a third entropy value, lock actions, retune Eq. (8), or fake traces.

**Phase 5 (continuous plant):** Fig 4a v35 late flats at 0.28352 were **bit-identical disconnected 2 s restarts** of pattern 0, not paper wiggles. Default Fig 4a to `plant_integration_mode=continuous` (Alg. 1 sequential 2 s carry; Python plant). Same ep0 knobs and τ_end **1.6** / entropy **0.15**. Fresh train — do not `--resume` v35. This removes ruler-flat segments; it does **not** by itself raise the late floor to ~0.37.

First continuous launch (`fig4ab-cont`) died in random warmup at step 10/100 (`ZeroDivisionError` in `run_cbgt_loop`). That run still used a **growing stitch** (~22 s at that step). STN intracellular Ca hit 0 and Numba `log(Cao/Ca)` divided by zero. Fix: floor Ca at $10^{-8}$ mM. Spike-buffer auto-size remains for long single-shot integrates (Fig 2a); 2 s carry stays at 512.

Second launch (`fig4ab-cont2`) died at warmup 50/100 — still stitch, ~44 s. Cause: striatal HH rates `alpham`/`betam`/`alphan`/`alphap`/`betap` are $0/0$ at $V=-54,-27,-52,-30$. 2 s almost never lands exactly there; a long stitch did. Fix: HH `vtrap` in Numba and `gating.py`. Continuous is now **sequential 2 s state-carry** (not a growing stitch), so wall-clock ≈ disconnected.

Third launch (`fig4ab-cont3`) used carry and still died at warmup 10/100 (~22 s accumulated). Remaining 0/0: HH time constants that underflow to 0 after `exp` overflow, then gate updates divide by $\tau$. Fix: floor $\tau$ and vtrap denominators.

**Phase 5 result (v36 series / 4b v37):** continuous 2 s carry finished (`fig4ab-cont4`, 777 s). 4a `gates_pass=true` (ep0 0.491 vs digitized 0.507; late step-mean 0.333). **0 bit-identical same-action $P_\beta$ runs** (longest equal-β streak length 1). Late pattern-0 streaks still exist (e.g. steps 267–299) but each step has a distinct β (~0.25–0.38). 4b still fails `late_beta_above_threshold` (0.321) and `late_reward_near_zero` (+7.0) — parked. Do not add entropy, skip_regular, or fake wiggles.

**Phase 6 (ep4 reward):** v37 episode 4 reward is **−52** vs digitized paper ~**−16** (episode-mean β 0.465 vs ~0.41). Cause: `critic_warmup_steps=100` skips actor updates for the first 100 training steps, so episode 4 (steps 120–149) has only ~20 actor updates and still samples 17 patterns. Paper-silent try: `--critic-warmup-steps 50` (same v36 knobs otherwise). Episode 0 is still before actor updates, so ep0 PSD should hold. Fresh train — do not `--resume` v36 (warmup is material).

```bash
uv run python -m rl_adaptive_dbs.run scripts/figures/papers/mehregan/4a/plot.py \
  --init-bias-scale 0 --jitter-fraction 0.5 --temperature-end 1.6 --entropy-coeff 0.15 \
  --critic-warmup-steps 50 --plant-integration continuous --push-kb --update-report
uv run python -m rl_adaptive_dbs.run scripts/figures/papers/mehregan/4b/plot.py --push-kb --update-report
```

**Phase 6 result (4a v31 / 4b v33):** warmup 50 finished (`fig4ab-ep4`, 778 s). Ep4 **−42.8**, ep5 **−29.1**, ep6 **−20.6** vs digitized **−55.3 / −26.4 / −5.9**. 4b **`gates_pass=true`**.

**Phase 7 (v32/v34):** warmup **25** — ep4 **−25.8**, ep6 **−18.3** improved but 4b **gates fail** (late β=0.316, reward +9). **v33** remains last pass.

**Phase 8:** warmup **50** + **`actor_lr=7.5e-4`** — faster mid-training without earlier actor start.

```bash
uv run python -m rl_adaptive_dbs.run scripts/figures/papers/mehregan/4a/plot.py \
  --init-bias-scale 0 --jitter-fraction 0.5 --temperature-end 1.6 --entropy-coeff 0.15 \
  --critic-warmup-steps 50 --actor-lr 7.5e-4 --plant-integration continuous --push-kb --update-report
```
